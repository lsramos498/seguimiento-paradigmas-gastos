# Código fuente

Cada carpeta contiene una implementación independiente del sistema de gastos personales.

- estructurada/: programación estructurada.
- poo/: programación orientada a objetos.
- eventos/: interfaz gráfica y manejo de eventos.
- declarativa/: consultas SQL o expresiones declarativas.
- funcional/: funciones puras y transformaciones de colecciones.

Todas las implementaciones deben cumplir las seis funcionalidades del README principal.
