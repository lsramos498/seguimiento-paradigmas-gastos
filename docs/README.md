# Documentación del proyecto

Sistema de Control de Gastos Personales desarrollado en Java para comparar cinco paradigmas de programación.

## Paradigmas

- Programación estructurada
- Programación orientada a objetos
- Programación orientada a eventos
- Programación declarativa con Java, SQLite y JDBC
- Programación funcional

La carpeta contiene la documentación general, las pruebas compartidas y el soporte de consulta bibliográfica.
