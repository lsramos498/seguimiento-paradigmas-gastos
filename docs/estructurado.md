# Paradigma estructurado
El paradigma estructurado organiza el programa en instrucciones secuenciales, condicionales, ciclos y funciones.
Se aplica mediante un menu de consola y metodos independientes para ejecutar las operaciones.
Los gastos se almacenan en arreglos paralelos de conceptos, montos y categorias, sin crear una clase Gasto.
El sistema permite registrar, listar, totalizar, identificar el mayor, filtrar por monto y buscar conceptos.
Compilar: `javac --release 17 -encoding UTF-8 -d out src/estructurado/Main.java`
Ejecutar: `java -cp out Main`
Ventaja: es directo y facil de seguir; limitacion: los arreglos tienen capacidad fija y los datos no persisten al cerrar.
